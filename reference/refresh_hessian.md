# The Log-Density's Curvature the Refresh Corrections Read

\\\ell\_{ab}\\ on the link scale, from whichever route the criterion's
\\K\\ was assembled on.

## Usage

``` r
refresh_hessian(spec, design, coef, expected = FALSE, approx = "bartlett")
```

## Arguments

- spec:

  A
  [`StatmodSpec()`](https://statmodels7.github.io/statmodels7/reference/StatmodSpec-class.md).

- design:

  The design.

- coef:

  The coefficients.

- expected:

  Whether the information is the expected one.

- approx:

  The approximation for the expected information.

## Value

A named list of numeric vectors.

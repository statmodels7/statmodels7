# The Largest Absolute Values

Returns the data frame of the `k` largest absolute values of `y`, with
the abscissa and the index as a label.

## Usage

``` r
diag_top(x, y, k = 5L)
```

## Arguments

- x, y:

  Numeric vectors.

- k:

  How many.

## Value

A data frame with the columns `x`, `y` and `label`.

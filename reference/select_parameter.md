# One Equation's Submatrix of a Variance Matrix

Returns the rows and columns of the named distribution parameters.

## Usage

``` r
select_parameter(V, param, spec)
```

## Arguments

- V:

  A variance matrix whose names are `parameter:name`.

- param:

  The distribution parameters to keep.

- spec:

  The fitted specification, for the message.

## Value

The submatrix.

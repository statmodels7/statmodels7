# The Kind of Each Label of a Profile

Builds the
[profiled_quantity](https://statmodels7.github.io/statmodels7/reference/profiled_quantity.md)
object of each label of `which`, from the context of the call.

## Usage

``` r
profile_quantities(ctx)
```

## Arguments

- ctx:

  The context of the call.

## Value

A list of
[profiled_quantity](https://statmodels7.github.io/statmodels7/reference/profiled_quantity.md)
objects, named by the labels.

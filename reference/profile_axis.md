# The Title and the Axis of a Profiled Quantity

The Title and the Axis of a Profiled Quantity

## Usage

``` r
profile_axis(q)
```

## Arguments

- q:

  A
  [profiled_quantity](https://statmodels7.github.io/statmodels7/reference/profiled_quantity.md)
  object.

## Value

A list with `title`, the label written as "parameter: name", and `x`,
the name of the quantity on the horizontal axis.

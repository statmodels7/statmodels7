# Effective Degrees of Freedom, Per Term

Asks each term what it spends, through modelterms7's `edf()`.

## Usage

``` r
statmod_edf(spec, coef, design, hyper)
```

## Arguments

- spec:

  The specification.

- coef:

  The coefficients.

- design:

  The design.

- hyper:

  The hyperparameters.

## Value

A data frame with one row per term.

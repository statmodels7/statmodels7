# Check That an Argument Is a Solver

Returns `x` invisibly when it inherits from
[IwlsSolver](https://statmodels7.github.io/statmodels7/reference/IwlsSolver.md)
and signals an error otherwise.

## Usage

``` r
check_solver(x)
```

## Arguments

- x:

  The value to check.

## Value

`x`, invisibly.

[iwls_solvers](https://statmodels7.github.io/statmodels7/reference/iwls_solvers.md)

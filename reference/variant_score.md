# The Score That Ranks the Versions of a Term

Returns a number that is smaller for a better fit: the outer criterion
with the sign that makes it a minimum, or the penalized objective where
no outer criterion ran.

## Usage

``` r
variant_score(fit)
```

## Arguments

- fit:

  A
  [StatmodFit](https://statmodels7.github.io/statmodels7/reference/StatmodFit-class.md).

## Value

A single number.

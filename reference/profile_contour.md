# The Contours of a Joint Profile Over Two Labels

Draws the contours of a joint profile over two of its labels, the
profile over any other label being the maximum over its grid.

## Usage

``` r
profile_contour(x, a, b)
```

## Arguments

- x:

  A
  [StatmodProfile](https://statmodels7.github.io/statmodels7/reference/StatmodProfile.md)
  object with `joint = TRUE`.

- a, b:

  The two labels.

## Value

A ggplot2 object.

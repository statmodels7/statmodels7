# The Name of the Criterion of a Profile

The Name of the Criterion of a Profile

## Usage

``` r
profile_criterion_name(x, label, column = x@profile_column[[label]])
```

## Arguments

- x:

  A
  [StatmodProfile](https://statmodels7.github.io/statmodels7/reference/StatmodProfile.md)
  object.

- label:

  A label of the profile.

- column:

  The column of `points` that is drawn.

## Value

A string for the axis of a graph.

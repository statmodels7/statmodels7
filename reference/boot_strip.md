# The Scheme as It Is Stored

Returns the scheme without the data frame of a cluster scheme, so that
an entry does not hold a copy of the data.

## Usage

``` r
boot_strip(x)
```

## Arguments

- x:

  A
  [resample_method](https://statmodels7.github.io/statmodels7/reference/resample_method.md)
  object.

## Value

A
[resample_method](https://statmodels7.github.io/statmodels7/reference/resample_method.md)
object.

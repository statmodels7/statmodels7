# Print a Test Statistic

Prints one line, the label of the statistic.

## Arguments

- x:

  A
  [test_statistic](https://statmodels7.github.io/statmodels7/reference/test_statistic.md)
  object.

- ...:

  Unused.

## Value

`x`, invisibly.

## Examples

``` r
print(lr_test())
#> <test> Likelihood-ratio
```

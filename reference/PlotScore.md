# S7 Class of the Score Graph

The class that
[`plot_score()`](https://statmodels7.github.io/statmodels7/reference/plot_score.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotScore(label = character(0), param = character(0), against = character(0))
```

## Arguments

- label, param, against:

  See
  [`plot_score()`](https://statmodels7.github.io/statmodels7/reference/plot_score.md).

## Value

A `PlotScore` object, inheriting from
[diagnostic_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

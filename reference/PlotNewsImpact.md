# S7 Class of the News-Impact Graph

The class that
[`plot_news_impact()`](https://statmodels7.github.io/statmodels7/reference/plot_news_impact.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotNewsImpact(
  label = character(0),
  range = integer(0),
  at = NULL,
  n_points = integer(0)
)
```

## Arguments

- label, range, at, n_points:

  See
  [`plot_news_impact()`](https://statmodels7.github.io/statmodels7/reference/plot_news_impact.md).

## Value

A `PlotNewsImpact` object, inheriting from
[term_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

# Does a Penalized Unit Belong to a Term

Does a Penalized Unit Belong to a Term

## Usage

``` r
unit_of_term(u, param, name)
```

## Arguments

- u:

  A unit from
  [`statmod_penalized()`](https://statmodels7.github.io/statmodels7/reference/statmod_penalized.md).

- param:

  The equation of the term.

- name:

  The name of the term.

## Value

A single logical.

# S7 Class of the PIT Histogram

The class that
[`plot_pit()`](https://statmodels7.github.io/statmodels7/reference/plot_pit.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotPit(
  label = character(0),
  legend = TRUE,
  bins = integer(0),
  seed = NULL,
  level = integer(0)
)
```

## Arguments

- label, bins, seed, level:

  See
  [`plot_pit()`](https://statmodels7.github.io/statmodels7/reference/plot_pit.md).

## Value

A `PlotPit` object, inheriting from
[diagnostic_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

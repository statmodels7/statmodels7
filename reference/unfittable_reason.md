# Why a Term Is Outside the Fitting Scheme

Returns the reason a term cannot be assembled as a fixed design block,
or the empty string when it can.

## Usage

``` r
unfittable_reason(term)
```

## Arguments

- term:

  One built term.

## Value

A single string.

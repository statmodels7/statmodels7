# Reject a Random Smooth in a Graph of a Random Effect

Reject a Random Smooth in a Graph of a Random Effect

## Usage

``` r
check_plain_random(type, x, ctx)
```

## Arguments

- type:

  The
  [plot_type](https://statmodels7.github.io/statmodels7/reference/plot_type.md)
  object.

- x:

  The term.

- ctx:

  The context of the graph.

## Value

`NULL`, invisibly.

# Check the Argument That Selects a Bootstrap Interval

Returns `x` if it is a
[bootstrap_interval](https://statmodels7.github.io/statmodels7/reference/bootstrap_interval.md)
object and signals an error that lists the constructors otherwise.

## Usage

``` r
as_boot_interval(x)
```

## Arguments

- x:

  The value of an `interval` argument.

## Value

`x`.

# The Name of a Fourth-Derivative Component

Locates the \\(a, b, k, q)\\ entry, by a name built from the parameter
names in the family's own order.

## Usage

``` r
d4_key(params, a, b, k, q, keys)
```

## Arguments

- params:

  The parameter names.

- a, b, k, q:

  Indices into `params`.

- keys:

  The names the derivative returned.

## Value

A single string.

# The Shift of One Mixture Component

The level a component adds to the predictor: one number for a regime or
a side pattern, one value per observation for a quadrature node.

## Usage

``` r
component_shift(mu, k)
```

## Arguments

- mu:

  What
  [`modelterms7::term_levels()`](https://statmodels7.github.io/modelterms7/reference/term_levels.html)
  returned.

- k:

  The component.

## Value

A single number or a vector over the observations.

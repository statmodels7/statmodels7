# The Kind of Inverse Link, for the Moments of a New Group's Parameter

The Kind of Inverse Link, for the Moments of a New Group's Parameter

## Usage

``` r
link_kind(g)
```

## Arguments

- g:

  A link.

## Value

`"identity"`, `"log"`, `"bounded"` (an inverse link bounded on both
sides), `"restricted"` (a predictor whose domain is not the whole line)
or `"other"`.

Signals an Error Where a Jeffreys Block Has No Usable Information

## Usage

``` r
jfp_check_ok(st)
```

## Arguments

- st:

  A state, from
  [`jfp_state()`](https://statmodels7.github.io/statmodels7/reference/jfp_state.md).

## Value

`NULL`, invisibly.

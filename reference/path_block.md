# The Block to Which a Path Row Belongs

The Block to Which a Path Row Belongs

## Usage

``` r
path_block(blocks, row)
```

## Arguments

- blocks:

  The blocks.

- row:

  One row of
  [`path_rows()`](https://statmodels7.github.io/statmodels7/reference/path_rows.md)'s
  index.

## Value

One entry of `blocks$sparse`.

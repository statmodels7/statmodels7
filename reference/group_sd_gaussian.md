# The Standard Deviation of h^-1(eta) for a Gaussian eta

The Standard Deviation of h^-1(eta) for a Gaussian eta

## Usage

``` r
group_sd_gaussian(g, m, s)
```

## Arguments

- g:

  The link.

- m, s:

  The mean and standard deviation of \\\eta\\, one a row.

## Value

The standard deviation of \\h^{-1}(\eta)\\, `NA` where the predictor's
domain is not the whole line.

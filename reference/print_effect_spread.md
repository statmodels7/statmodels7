# Print the Summary of a Term's Predicted Random Effects

Prints what
[`effect_spread()`](https://statmodels7.github.io/statmodels7/reference/effect_spread.md)
returns under the heading `predicted effects (m levels of g)`, one row
per coordinate.

## Usage

``` r
print_effect_spread(sp, indent = 2L, digits = 4L)
```

## Arguments

- sp:

  What
  [`effect_spread()`](https://statmodels7.github.io/statmodels7/reference/effect_spread.md)
  returns.

- indent:

  The indentation of the heading.

- digits:

  Significant digits.

## Value

`NULL`, invisibly. Called for the printing.

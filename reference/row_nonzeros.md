# A Design's Nonzeros, Ordered by Row

A Design's Nonzeros, Ordered by Row

## Usage

``` r
row_nonzeros(X)
```

## Arguments

- X:

  A sparse design block.

## Value

A list with `i`, `j` and `v`, sorted by row.

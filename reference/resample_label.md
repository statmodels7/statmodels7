# The Words That Name a Resampling Scheme

Returns the name of the scheme, followed by the formula of a cluster
scheme. It is also the key by which stored bootstrap entries are
matched.

## Usage

``` r
resample_label(x)
```

## Arguments

- x:

  A
  [resample_method](https://statmodels7.github.io/statmodels7/reference/resample_method.md)
  object.

## Value

A single string.

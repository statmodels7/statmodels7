# The Rows of a Density Graph

Completes the covariate rows of
[`plot_density()`](https://statmodels7.github.io/statmodels7/reference/plot_density.md)
with the other variables of the model.

## Usage

``` r
density_rows(type, fit, ctx)
```

## Arguments

- type, fit, ctx:

  The graph type, the fit and the context of
  [`plot_data()`](https://statmodels7.github.io/statmodels7/reference/plot_data.md).

## Value

A list with `nd`, `at` and `data`.

# Check the Argument That Selects a Resampling Scheme

Returns `x` if it is a
[resample_method](https://statmodels7.github.io/statmodels7/reference/resample_method.md)
object and signals an error that lists the constructors otherwise.

## Usage

``` r
as_resample_method(x)
```

## Arguments

- x:

  The value of a `resample` argument.

## Value

`x`.

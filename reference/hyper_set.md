# Set One Hyperparameter

Set One Hyperparameter

## Usage

``` r
hyper_set(hyper, row, value)
```

## Arguments

- hyper:

  The hyperparameters.

- row:

  One row of
  [`path_rows`](https://statmodels7.github.io/statmodels7/reference/path_rows.md)'s
  index.

- value:

  The value to write.

## Value

The hyperparameters, with that one changed.

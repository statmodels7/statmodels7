# Starting Values From a Random Draw

The draw, added to the intercept-only fit unless told not to.

## Arguments

- strategy:

  A `StartRandom` object.

- spec, design, obj, ...:

  As in
  [`start_at`](https://statmodels7.github.io/statmodels7/reference/start_at.md).

## Value

A named list of numeric vectors.

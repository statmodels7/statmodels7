# The Scaling Exponent of a Filter

The `scaling` of a
[`modelterms7::gas()`](https://statmodels7.github.io/modelterms7/reference/gas.html)
term, and zero for a structural term that has none.

## Usage

``` r
filter_scaling(tm)
```

## Arguments

- tm:

  A structural term.

## Value

A single number.

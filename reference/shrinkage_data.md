# The Data of a Shrinkage Graph

The Data of a Shrinkage Graph

## Usage

``` r
shrinkage_data(type, x, fit, ctx)
```

## Arguments

- type:

  A `PlotShrinkage` object.

- x:

  The term.

- fit:

  A
  [`StatmodFit()`](https://statmodels7.github.io/statmodels7/reference/StatmodFit-class.md).

- ctx:

  The context described at
  [`plot_data()`](https://statmodels7.github.io/statmodels7/reference/plot_data.md).

## Value

A list with the data frame `estimates` and the attribute `"labels"`.

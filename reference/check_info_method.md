# Check the Method Given to an Information Object

Returns `method` invisibly when it is `NULL` or inherits from
[distributions7::ExpectMethod](https://statmodels7.github.io/distributions7/reference/ExpectMethod.html)
and signals an error otherwise.

## Usage

``` r
check_info_method(method)
```

## Arguments

- method:

  The value to check.

## Value

`method`, invisibly.

# The Axis Title of the Levels of a Random Term

Names the grouping of a random term, as in "level of id", for the axis
on which a graph lists its levels.

## Usage

``` r
random_group_label(tm)
```

## Arguments

- tm:

  A
  [modelterms7::RandomTerm](https://statmodels7.github.io/modelterms7/reference/RandomTerm.html).

## Value

A single string, or `NULL` when the term records no grouping.

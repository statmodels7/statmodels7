# S7 Class of the State-Probability Graph

The class that
[`plot_states()`](https://statmodels7.github.io/statmodels7/reference/plot_states.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotStates(label = character(0), smoothed = logical(0))
```

## Arguments

- label, smoothed:

  See
  [`plot_states()`](https://statmodels7.github.io/statmodels7/reference/plot_states.md).

## Value

A `PlotStates` object, inheriting from
[term_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

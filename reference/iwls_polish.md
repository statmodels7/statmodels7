# Whether an Inner Fit Takes One Step Past Its Stopping Rule

`TRUE` where
[`iwls_fit()`](https://statmodels7.github.io/statmodels7/reference/iwls_fit.md)
takes a full step at the point its rule accepted, so a criterion read
there is out by a second-order amount.

## Usage

``` r
iwls_polish()
```

## Value

A single logical.

## See also

[`iwls_fit()`](https://statmodels7.github.io/statmodels7/reference/iwls_fit.md).

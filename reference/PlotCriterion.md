# S7 Class of the Criterion Graph

The class that
[`plot_criterion()`](https://statmodels7.github.io/statmodels7/reference/plot_criterion.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotCriterion(
  label = character(0),
  legend = TRUE,
  log_lambda = NULL,
  method = character(0),
  hyper = NULL
)
```

## Arguments

- label, log_lambda, method, hyper:

  See
  [`plot_criterion()`](https://statmodels7.github.io/statmodels7/reference/plot_criterion.md).

## Value

A `PlotCriterion` object, inheriting from
[term_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

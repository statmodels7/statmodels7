# The Contribution of a Smooth at Fitted Coefficients

The Contribution of a Smooth at Fitted Coefficients

## Usage

``` r
parts_contribution_values(fit, param, name, tm, newdata)
```

## Arguments

- fit:

  A
  [`StatmodFit()`](https://statmodels7.github.io/statmodels7/reference/StatmodFit-class.md).

- param, name, tm:

  The equation, the name and the smooth term.

- newdata:

  A data frame.

## Value

A numeric vector with one value for each row of `newdata`.

# The Linear Predictors' Parameters at the Context's Point

The Linear Predictors' Parameters at the Context's Point

## Usage

``` r
ctx_theta(ctx, spec, design, coef, hyper)
```

## Arguments

- ctx:

  A context, or `NULL`.

- spec, design, coef, hyper:

  The fallback arguments.

## Value

A named list, one entry per distribution parameter.

# A Subtable of the Hyperparameters, With Its Attributes

A Subtable of the Hyperparameters, With Its Attributes

## Usage

``` r
profile_hyper_rows(htab, rows)
```

## Arguments

- htab:

  The table of
  [`profile_hyper_table()`](https://statmodels7.github.io/statmodels7/reference/profile_hyper_table.md),
  with the column `row`.

- rows:

  Row numbers of `htab`.

## Value

The rows, with the attributes `links` and `members` of `htab`.

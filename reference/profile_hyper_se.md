# The Standard Errors of the Held Hyperparameters on the Scale of Their Links

The Standard Errors of the Held Hyperparameters on the Scale of Their
Links

## Usage

``` r
profile_hyper_se(ctx)
```

## Arguments

- ctx:

  The context of the call.

## Value

A numeric vector with one element for each held hyperparameter, `NA`
where the standard error is not available.

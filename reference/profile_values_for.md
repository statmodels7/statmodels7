# The Argument values for a Subset of the Labels

Keeps, of a list `values` of
[`statmod_profile()`](https://statmodels7.github.io/statmodels7/reference/statmod_profile.md),
the elements that name a label of `which` and the element without a
name, so that a list written for every label serves a profile of some of
them.

## Usage

``` r
profile_values_for(values, which)
```

## Arguments

- values:

  The argument `values`.

- which:

  The labels of the profile.

## Value

`values`, possibly shortened.

# The Method of a Diagnostic Graph for a Multivariate Family

Signals an error: quantile residuals are defined for a univariate
response.

## Usage

``` r
diag_multivariate(type, x, fit, ctx, ...)
```

## Arguments

- type:

  A diagnostic
  [plot_type](https://statmodels7.github.io/statmodels7/reference/plot_type.md)
  object.

- x, fit, ctx, ...:

  As in
  [`plot_data()`](https://statmodels7.github.io/statmodels7/reference/plot_data.md).

## Value

Nothing: the function signals an error.

# The Two-Sided P-Value of a Wald Statistic

The Two-Sided P-Value of a Wald Statistic

## Usage

``` r
wald_pvalue(stat, df = NULL)
```

## Arguments

- stat:

  The statistics \\z\\.

- df:

  `NULL` for the normal distribution, otherwise the degrees of freedom,
  one for each statistic (`Inf` for the normal).

## Value

A numeric vector.

# The Legend of a Covariance Block

One line per coordinate, giving its label and the term it comes from,
for the head of the block a summary prints.

## Usage

``` r
coord_legend(cd)
```

## Arguments

- cd:

  The coordinates, as
  [`class_coords()`](https://statmodels7.github.io/statmodels7/reference/class_coords.md)
  returns them.

## Value

A character vector.

# S7 Class of the Regime-Density Graph

The class that
[`plot_regime_density()`](https://statmodels7.github.io/statmodels7/reference/plot_regime_density.md)
instantiates. Use the constructor, which checks the properties.

## Usage

``` r
PlotRegimeDensity(label = character(0), at = NULL, n_grid = integer(0))
```

## Arguments

- label, at, n_grid:

  See
  [`plot_regime_density()`](https://statmodels7.github.io/statmodels7/reference/plot_regime_density.md).

## Value

A `PlotRegimeDensity` object, inheriting from
[term_plot](https://statmodels7.github.io/statmodels7/reference/plot_type.md).

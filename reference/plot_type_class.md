# The Class of the Graph Types

Returns the S7 class `plot_type`. The argument `plot_type` of
[`autoplot.StatmodFit()`](https://statmodels7.github.io/statmodels7/reference/autoplot.StatmodFit.md)
hides the class inside that function, which calls this function to reach
it.

## Usage

``` r
plot_type_class()
```

## Value

The S7 class `plot_type`.

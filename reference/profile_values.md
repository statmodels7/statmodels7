# The Values of a Profile for Each Coefficient

Turns the argument `values` of
[`statmod_profile()`](https://statmodels7.github.io/statmodels7/reference/statmod_profile.md)
into one sorted numeric vector for each label.

## Usage

``` r
profile_values(ctx, values)
```

## Arguments

- ctx:

  The context of the call.

- values:

  The argument `values`.

## Value

A named list of numeric vectors.

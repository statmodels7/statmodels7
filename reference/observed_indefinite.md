# Whether a Family's Observed Information Can Be Indefinite

Returns `TRUE` for a Student t, a skew t or a Cauchy response, including
a family that has one of them as its parent. The log-density of these
families is not concave in the location.

## Usage

``` r
observed_indefinite(distrib)
```

## Arguments

- distrib:

  A family.

## Value

A single logical.

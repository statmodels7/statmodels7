# Check the Argument That Selects a Test Statistic

Returns `test` if it is a
[test_statistic](https://statmodels7.github.io/statmodels7/reference/test_statistic.md)
object and signals an error that lists the four constructors otherwise.

## Usage

``` r
as_test_statistic(test, arg = "test")
```

## Arguments

- test:

  The value of a `test` argument.

- arg:

  The argument's name, for the message.

## Value

`test`.
